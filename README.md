# Null Propagation

**Not knowing isn't the problem. Forgetting what we don't know is.**

Exploring uncertainty through statistics, simulations, machine learning, science, and critical thinking.

We build experiments, investigate assumptions, and use data to challenge intuition. Sometimes the results are surprising. Sometimes the models are wrong. Both are interesting.

- **Statistics & Machine Learning** — Understanding models, assumptions, and limitations.
- **Data Engineering** — Building reproducible pipelines and analytical tools.
- **Science & Critical Thinking** — Exploring the distance between evidence and certainty.
